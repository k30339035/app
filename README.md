## 🎮 상용 게임 수준 기능

### ✨ 완전한 게임 시스템
- ✅ **다양한 무기**: 레이저, 미사일, 레일건
- ✅ **업그레이드 시스템**: 7가지 업그레이드 (체력, 쉴드, 데미지, 연사력, 속도, 미사일, 레일건)
- ✅ **업적 시스템**: 7개 업적 with 크레딧 보상
- ✅ **보스전**: 5 웨이브마다 보스 등장
- ✅ **콤보 시스템**: 연속 격추로 보너스 점수
- ✅ **파워업**: 체력, 쉴드, 미사일 회복
- ✅ **쉴드 시스템**: 체력 보호 + 자동 재생

### 🎨 AAA급 그래픽
- **Babylon.js 6.0** 3D 엔진
- **PBR Materials** 물리 기반 렌더링
- **Bloom & Glow** 포스트 프로세싱
- **GPU Particles** 파티클 시스템
- **Dynamic Lighting** 실시간 조명

### 🎵 완전한 사운드 시스템
- Web Audio API 기반
- 프로시저럴 사운드 생성
- 레이저, 폭발, 파워업 효과음
- 마스터/음악/효과음 별도 볼륨 조절

### 🎯 게임 모드
1. **스토리 모드** - 캠페인 미션
2. **서바이벌** - 무한 웨이브
3. **보스 러시** - 연속 보스전
4. **협동 플레이** - 멀티플레이어

## 🛠️ 기술 스택

```
Babylon.js 6.0  (3D Engine)
WebGL 2.0       (Graphics)
Web Audio API   (Sound)
PBR Materials   (Rendering)
Post-Processing (Effects)
```

## 🎮 조작법

**이동**: W/A/S/D 또는 방향키
**상승/하강**: Q / E
**발사**: Space
**무기 전환**: 1 / 2 / 3
**일시정지**: ESC

## 📊 게임 시스템

### 업그레이드
- 체력 +20% (레벨당)
- 쉴드 +20%
- 데미지 +20%
- 연사력 +20%
- 속도 +20%
- 미사일 장착
- 레일건 장착

### 업적
- 첫 격추 (+500 크레딧)
- 웨이브 5 도달
- 100기 격추
- 보스 처치
- 50 콤보 달성
- 완벽한 승리
- 스피드런

## 💎 크레딧 시스템
- 적 격추: +100 (기본)
- 콤보 보너스: +(100 × 콤보 × 0.1)
- 보스 격파: +5000
- 업적: +500
