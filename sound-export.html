🔊 Sound Export Tool

사용 방법

  1. 각 사운드의 "Preview" 버튼을 클릭하여 미리듣기
  2. "Download WAV" 버튼을 클릭하여 WAV 파일로 다운로드
  3. 다운로드한 WAV 파일을 MP3로 변환 (아래 방법 참조)

MP3 변환 방법

방법 1: 온라인 변환기

  • CloudConvert
  • Online Audio Converter

방법 2: FFmpeg (권장)

ffmpeg -i sound.wav -codec:a libmp3lame -qscale:a 2 sound.mp3

방법 3: Audacity

  • Audacity에서 WAV 파일 열기
  • File → Export → Export as MP3
